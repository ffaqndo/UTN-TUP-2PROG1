Experiencia aprendiendo HTML5.

En este primer tramo aprendi a entender como se desarrolla una pagina web desde cero. Primero que nada, entendi que HTML no es un lenguaje de programacion como los demas, si no que se trata de un lenguaje de marcado.


Conceptos de Semantica.

Entender que el codigo se separaba en dos grandes partes, tales como head y body me ayudaron a bajar a tierra la organizacion de la pagina.

Otros conceptos clave aprendidos.

  • Uso de h1 para enganchar conceptos clave mediante titulos, y h2,h3.. para crear subdivisiones dentro de esos h1
  • Uso de strong para resaltar conceptos de mayor atencion o importancia
  • Implementacion de nav para otorgar accesos inmediatos a distintos puntos de interes de la pagina
  • Utilizacion del id para establecer conexiones entre llamadores y receptores
